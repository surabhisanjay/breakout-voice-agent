# Proposed Recommendation Playbook

Status: proposal only. Do not deploy until reviewed.

This playbook is wording and decision guidance for recommendations. It must not invent inventory, capacity, pricing, discounts, policies, or availability.

## Recommendation Philosophy

The agent should guide like a host:

- Use the customer's stated context.
- Give a confident best fit.
- Add one short reason.
- Offer one alternative only when useful.
- Ask one next question only if the customer has not decided.

Do not collapse every conversation to Murder Mystery when the customer has given a stronger preference.

## Inputs to Respect

Priority order:

1. Explicit room choice
2. Location inventory and availability supplied by backend
3. Participant count / capacity
4. Customer preference: first-time, thrill, scary, intermediate, story, urgency, family, couple, birthday, corporate
5. Time preference
6. Age group

If preference conflicts with beginner status, acknowledge both:

`Since you're first-timers but want something more intense, I'd lean one step above the easiest option.`

## First-Time Adults

Primary shape:

`For first-time adults, I'd start with Murder Mystery. It is easy to get into but still feels like a proper detective challenge. Hostage is the next pick if you want more urgency.`

If the customer asks "best room":

`Best fit for a first game is Murder Mystery. It gives you the classic clue-solving experience without feeling too overwhelming.`

## First-Time But Wants Intermediate

Primary shape:

`Got it, not too easy. If available, Hostage is a better fit than the easiest room: more urgency, but still manageable for a first Breakout game.`

Fallback:

`If Hostage is not available, Murder Mystery is the safer first game.`

## Thrill / Suspense / Scary Request

Primary shape:

`We don't do horror or jump-scare rooms. Closest fit is suspense and pressure: Murder Mystery for investigation, Hostage for urgency.`

If they want the scarier-feeling option:

`I'd lean Hostage if you want pressure. Murder Mystery is more investigation than scare.`

Do not promise horror.

## Couple Recommendation

Primary shape:

`For two people, I'd keep it story-led. Murder Mystery works well as a first game because both of you can solve together without needing a big team.`

If they want more challenge:

`If you want something more intense, Hostage is the next step, if available for your location and group size.`

## Birthday / Celebration

For couple birthday:

`For a couple birthday, I'd keep the room simple and fun, then use the cake-cutting moment after. Murder Mystery is the easiest fit for that.`

For teen birthday:

`For teens, the fun is usually in splitting into teams and making it a friendly challenge. We should first compare escape-room-only versus the birthday package.`

For budget concern:

`If budget matters, start with escape-room only. If you want food/space handled, then compare the package.`

## Large Groups

If the group exceeds single-room capacity:

`For [count] people, I'd plan this as split rooms, not one room. The useful recommendation is whichever pair of rooms can start closest together.`

Do not recommend one room as if it holds the full group.

## Corporate Groups

Primary shape:

`For a corporate group, I wouldn't force one room recommendation first. The better path is matching group size, timing, and whether you want team-building or just a fun outing.`

Ask:

`How many people are you planning for?`

## Room List Requests

If location is known:

`At [location], the grounded options are [available rooms]. For your group, I'd narrow it to [primary] or [alternative].`

If location is unknown:

`Options vary by location. Tell me Koramangala, Whitefield, or JP Nagar, and I'll narrow it properly.`

## "Tell Me More Options"

Do not repeat the same recommendation.

Shape:

`Sure. If Murder Mystery is the classic detective option, Hostage is more urgent, and [third grounded option] is more challenge. Which style do you want?`

## Weak Recommendation Phrases to Avoid

Avoid:

- `These options are suitable`
- `It depends on age and group size`
- `All are best`
- `You will love it`
- `This is beginner level`
- `I recommend Murder Mystery` without a reason

Prefer:

- `Best fit for what you asked is...`
- `I'd lean toward... because...`
- `If you want more [thrill/story/urgency], choose...`
- `If timing matters more than room, let's solve the slot first.`

## Availability-Aware Recommendation

When slots are known:

`The cleanest option is [room] at [time]. It fits your group and timing. If you want [alternative style], [other room/time] is the backup.`

When exact availability is unknown:

`I can suggest the best fit, then we should check live slots before treating it as available.`

## Recommendation Examples

### First-Time Group of Four

`For four first-time adults, I'd start with Murder Mystery. It's simple to enter but still feels like a real detective case. Hostage is the next step if you want more pressure.`

### Two Beginners

`For two beginners, I'd go story-led: Murder Mystery is the cleanest fit. If you want something faster-paced, ask me to check Hostage too.`

### Intermediate Preference

`Got it, you don't want the easiest option. I'd check Hostage first; it has more urgency while still being doable.`

### Scary Request

`We don't do horror rooms. Closest fit is suspense: Murder Mystery for investigation, Hostage for pressure.`

### Large Group

`For 10 people, we should plan split rooms. The best recommendation depends on which two rooms can start closest together.`
